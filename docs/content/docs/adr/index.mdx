---
title: Architecture Decision Records
description: The decisions that were expensive to reverse or actually debated — and the debt each one carries.
---

An ADR is written when a decision is **costly to reverse** or **was genuinely
debated**. Not for every library pick.

ADRs are **immutable**. An accepted one is never rewritten; it is superseded by a
new one, and both stay. The value is in reading what we believed at the time,
including where we turned out to be wrong.

Each record states its **accepted debt**: what we knowingly deferred, and what would
make us revisit it. A decision without a stated cost is usually a decision that has
not been thought through.

```bash
task adr -- "the decision title"   # creates the next numbered record from the template
task adr:list                      # lists them with their status
```
