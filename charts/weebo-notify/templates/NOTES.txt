{{- if not .Values.server.database.existingSecret }}

WARNING: server.database.existingSecret is unset. notify-server will start with
no WNK_DATABASE__URL and refuse to connect. Create a Secret carrying the
Postgres DSN and point server.database.existingSecret at it.
{{- end }}

{{- if not .Values.web.env.apiBaseUrl }}

WARNING: web.env.apiBaseUrl is unset. The web bundle needs the server's own
public origin (e.g. https://{{ .Values.server.ingress.host }}) to know where to
call — set it explicitly, it is never guessed from server.ingress.host.
{{- end }}

only. This release runs server.replicaCount=1 regardless of the configured
value, and its PodDisruptionBudget/HorizontalPodAutoscaler are skipped.
{{- end }}

{{- if and .Values.server.autoscaling.enabled (not .Values.server.autoscaling.customMetrics) }}

sse_connections off /metrics — not bundled here. Add entries under
server.autoscaling.customMetrics once one is wired up.
